# PCC — Personal Control Center

A centralized personal operating system that brings together all aspects of your life in one place.

## What is PCC?

PCC consolidates tasks, projects, calendar, goals, notes, finances, fitness, and more into a unified platform. Instead of juggling multiple apps, get everything you need to know in one place:

- **What's happening right now?**
- **What needs my attention?**
- **What's coming next?**
- **What have I been neglecting?**

## Features

- Tasks & Projects
- Kanban Boards
- Calendar & Reminders
- Goals & Career Management
- Notes & Ideas
- Personal Finance & Fitness
- Weather & Timers
- AI-Assisted Planning
- Personal CRM
- Weekly Reviews

## Tech Stack

**Frontend:** React + TypeScript + Vite
**Backend:** Python + FastAPI + SQLAlchemy  
**Database:** PostgreSQL  
**Platforms:** Desktop Web, Mobile Web, PWA
