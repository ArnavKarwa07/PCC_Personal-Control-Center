# Shared Utilities & Common Libraries

This directory contains shared code, data structures, and utilities reused across the Personal Control Center (PCC) backend, workers, and tools.

## Contents
- **Schemas & DTOs**: Cross-service data definitions and validation models.
- **Utilities**: Common helper functions (e.g., date/time parsers, crypto helpers, logging configurations).
- **Constants**: Shared system constants, error codes, and configuration defaults.
