# Infrastructure & Deployment Configurations

This directory contains infrastructure-as-code, deployment manifests, CI/CD pipeline definitions, and server configuration files for the Personal Control Center (PCC).

## Structure & Purpose
- **Docker / Containers**: Dockerfiles and container orchestration manifests for production and staging environments.
- **CI/CD**: Automation scripts and deployment pipelines (e.g. GitHub Actions, deployment hooks).
- **Reverse Proxy / Gateway**: Nginx, Caddy, or Traefik configuration files.
- **Database Migrations & Backups**: Automated backup routines and database disaster recovery scripts.
